# Security Policy

## Supported versions

The `main` branch is the supported version.

## Reporting a vulnerability

Please open a private security advisory on GitHub if available, or contact the repository owner directly.

Do not post secrets, microphone recordings, local app inventories, or personal notes in public issues.

## Local safety expectations

- JARVIS runs on your own laptop and launches local apps only after a recognized command.
- Generated notes and the Start Menu app cache are ignored by git.
- Startup automation is installed for the current Windows user only.
- Unknown app names should not silently turn into browser searches.
